# Open Companion

一个面向 AstrBot 的通用私聊角色连续性插件。它在每次私聊请求前补充轻量的短期角色状态，让使用者可以自己配置名字、称呼、风格、心情、显式偏好和安静时段。

它不绑定任何特定 QQ 号，默认账号留空；配置账号后才生效。状态按平台实例、机器人账号和用户账号隔离。

## 功能

- 规则生成“平静、开心、得意、好奇、关切”等短期心情，并按半衰期淡化。
- 只通过命令保存长期偏好，避免自动把玩笑、引用或临时情绪当成事实。
- 可选自动提取：从明确的“叫我……”“我喜欢……”或表达习惯短句中保存少量偏好，默认关闭。
- 保存最近若干条回复文本，用于减少固定结尾和重复表达。
- 识别睡觉、健身、忙碌等明确表述，给现有主动聊天插件提供安静时段保护。
- 识别 QQ Face 编号但不猜未知表情的具体含义。
- 不额外调用模型，不创建第二套主动消息调度器，不执行 QQ 操作。

## 安装

在 AstrBot WebUI 的插件页面选择“本地安装”，上传发布包 `astrbot_plugin_companion_generic.zip`。安装后打开配置并填写：

- `owner_qq`：允许使用插件的用户 QQ 号。
- `bot_qq`：机器人 QQ 号。
- `platform_name`：QQ 通常为 `aiocqhttp`。
- `platform_id`：有多个实例时填写对应实例；单实例可留空。

账号留空时插件不会处理任何私聊。群聊永远不处理。

## 个性化配置

### 基本身份

`bot_name` 只用于状态回复。称呼、身份和角色可以写进 `guidance_text`，例如：

```text
机器人叫小月，用户可以叫阿辰。语气像熟悉的妹妹，温柔但有主见；不必每句称呼用户。
```

### 初始偏好

`initial_preferences_json`：

```json
{"称呼用户":"阿辰","语言":"中文","表情":"少量使用","不喜欢":"每句话都问问题"}
```

之后还可以在私聊中使用“伴侣记住”命令增加偏好。

### 自动提取记忆

配置页将 `auto_memory_enabled` 打开后，插件会尝试从普通私聊中提取三类明确表达：

```text
以后叫我阿辰
我喜欢无糖茶
回复简短一点
```

自动保存前会跳过较长内容、疑问句、引号/引用、转发、例子、假设、不确定表达、敏感凭据和规则注入文字。每条消息最多保存 `auto_memory_max_per_message` 条，最多不超过 `max_preferences` 条。

自动记忆不会覆盖手动保存的同名偏好。使用 `/伴侣忘记 偏好名` 后，该名称会暂时加入忽略列表，普通聊天不会马上重新记回；需要恢复时用 `/伴侣记住 偏好名=新内容`。

`/伴侣记忆` 会标出 `[自动]`、`[手动]` 或 `[初始]` 来源。建议先打开开关，再用明确短句测试；如果不希望自动保存，保持关闭即可。

### 心情表达

`mood_text_json`：

```json
{"得意":"可以有一点小得意，偶尔轻轻邀功","关切":"先陪伴和回应，不自动给三条建议","开心":"轻快一点，但不要每句都夸张"}
```

`mood_half_life_minutes` 控制心情持续时间。45 表示强度大约每 45 分钟衰减一半，范围 5—240。

### 自定义触发

`mood_trigger_json` 使用正则 JSON：

```json
{"happy":"(?:太好了|好开心|赢了)","proud":"(?:猜对|你真棒)"}
```

键名支持 `happy`、`proud`、`curious`、`care`。正则错误会被忽略并继续使用其他规则。

`activity_rules_json` 示例：

```json
{"sleep_pattern":"(?:我去睡|晚安)","sleep_quiet_minutes":120,"return_pattern":"(?:我醒了|起床了)"}
```

支持 `sleep_pattern`、`exercise_pattern`、`busy_pattern`、`return_pattern` 和相应的 `sleep_quiet_minutes`、`exercise_quiet_minutes`、`busy_quiet_minutes`。

### 自定义行为说明

`guidance_text` 会在每次请求中加入提示。适合填写稳定的表达偏好：少用 emoji、不要 Markdown、允许不同意见、收到表情包直接接话等。

不要写入 API Key、Cookie、密码，也不要让它忽略系统规则、伪造工具成功或编造现实经历。

## 私聊命令

命令使用 AstrBot 注册的固定触发名，前缀为 `/伴侣`：

```text
/伴侣帮助
/伴侣状态
/伴侣记忆
/伴侣记住 偏好名=具体内容
/伴侣忘记 偏好名
/伴侣安静 90
/伴侣恢复
/伴侣重置 确认
```

命令只作用于本插件自己的 SQLite 数据，不删除 AstrBot 聊天记录或其他记忆插件的数据。

## 数据与限制

数据保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_companion_generic/state.sqlite3`，不会发送到额外服务。状态和自动提取的偏好会随正常请求进入你配置的模型提供方。只保存有限的近期回复，不保存模型思考、图片或工具结果。

插件不会修复上游丢失的 QQ 表情，不会解决模型中转超时，也不会控制其他插件直接发送的主动消息。安静时段只兼容会派发标准 LLM 请求钩子的主动聊天插件。

它模拟的是连贯的角色表达，不代表真实意识或心理诊断。复杂否定、反讽和引用可能需要手动调整规则。

## 验证

核心状态引擎可用 Python 标准库测试。安装后建议先在目标私聊测试 `/伴侣状态`，再测试“记住”“忘记”和安静时段，最后观察普通对话是否仍正常回复。
